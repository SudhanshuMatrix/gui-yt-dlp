# Security Policy

## Supported Versions

Only the latest release of **gui-yt-dlp** is currently supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within **gui-yt-dlp**, please report it responsibly:

1. **Do NOT open a public GitHub issue.**
2. Send an email to the maintainer detailing the vulnerability.
3. Include detailed steps to reproduce the issue, along with any relevant proof-of-concept scripts or logs.

We will acknowledge receipt within 48 hours and provide updates on resolution status.
